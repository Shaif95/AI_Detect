Proving What Is Real

This is the checker API behind the project's Firefox add-on. It answers one question: was this text likely written by AI?

Health check: GET /api/check. Run a check: POST /api/check with a JSON body of {"text": "..."}.

The detection model is Hello-SimpleAI/chatgpt-detector-roberta, served through Hugging Face. Text sent here is processed for the check and is not stored or used to train models.
